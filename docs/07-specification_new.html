機能詳細仕様書

1. システム概要

サービス名: ペットライフプラス（Pet Life Plus）

利用者: 管理者、一般ユーザー

目的: ペットの健康記録、AI症状チェック、予約、診療・相談履歴を一元管理し、早期異変の発見、受診判断の支援、継続的な健康管理を実現する。

2. システム構成

  • フロントエンド: HTML / CSS / JavaScript（Thymeleaf）
  • バックエンド: Spring Boot（Controller → Service → Repository）
  • データベース: H2 / MySQL

4. 機能詳細仕様

F-001: ログイン認証

メールアドレス/パスワードで認証し、成功時にセッションを発行してダッシュボードへ遷移する。

画面レイアウト

メールアドレス入力、パスワード入力、ログインボタン、再設定リンクを配置。

処理フロー

  1. 認証情報を入力する。
  2. ログインボタン押下で認証処理を実行する。
  3. 認証結果に応じて遷移またはエラー表示する。

正常時の動作

認証成功でセッションを作成し、ダッシュボードへ遷移する。

エラー時の動作

バリデーション: 未入力・形式不正を項目下に表示。システム: 認証処理失敗時に汎用エラーメッセージを表示。

入力項目一覧

項目名データ型必須バリデーション
メールアドレスString○必須 / メール形式 / 255文字
パスワードString○必須 / 8〜64文字

F-002: ダッシュボード表示

KPI・通知・本日の予定を表示し、各管理画面への導線を提供する。

画面レイアウト

KPIカード、本日の予定、通知一覧、メニュー導線を配置。

正常時の動作

最新データを表示し、各機能に遷移できる。

F-003: ユーザー管理（CRUD）

ユーザー情報の一覧表示、登録、詳細表示、編集、削除を行う。

処理フロー

  1. 検索または対象ユーザーを選択する。
  2. 登録/更新/削除を実行する。
  3. 保存後に一覧を再表示する。

入力項目一覧

項目名データ型必須備考
氏名String○1〜50文字
メールアドレスString○一意制約
電話番号String-任意（10〜13桁）

F-004: ペット管理（CRUD）

ペット情報の登録、参照、更新、削除を行い、飼い主情報と紐付ける。

入力項目一覧

項目名データ型必須備考
ペット名String○1〜40文字
種別Enum○犬 / 猫 など
生年月日Date-未来日不可

F-005: 健康記録管理（CRUD）

体重・食事・運動などの健康記録を登録し、時系列で管理する。

入力項目一覧

項目名データ型必須バリデーション
記録日Date○日付形式
体重Decimal-0.1〜200.0
食事メモString-300文字以内

F-006: 予約管理（CRUD）

診療・相談予約の登録、変更、キャンセルを管理し、空き枠チェックを行う。

処理フロー

  1. 予約条件を入力する。
  2. 空き枠と重複をチェックする。
  3. 成功時に一覧へ反映する。

入力項目一覧

項目名データ型必須備考
予約日時DateTime○過去日時不可
予約種別Enum○診療 / 相談

F-007: 診療・相談履歴管理（CRUD）

診療・相談履歴の登録、検索、編集、削除と添付管理を行う。

入力項目一覧

項目名データ型必須備考
実施日Date○日付形式
対応内容String○1000文字以内
添付ファイルFile-PDF・画像（5MB以内）

F-009: AI症状チェック

症状入力を解析し、重症度と推奨対応（経過観察/相談/受診）を提示する。

処理フロー

  1. 症状種別、発症時期を入力する。
  2. AI解析を実行する。
  3. 判定結果（重症度・推奨アクション）を表示する。

F-011: 請求・決済管理

請求作成、入金確認、支払状況の更新、領収書発行を行う。

入力項目一覧

項目名データ型必須備考
請求金額Decimal○0以上
請求日Date○日付形式
支払状況Enum○未払い / 入金済み

F-012: 通知・リマインド配信

通知作成、配信対象設定、配信実行、配信履歴管理を行う。

入力項目一覧

項目名データ型必須備考
件名String○100文字以内
本文String○2000文字以内
配信日時DateTime-予約配信の場合必須

F-013: PDF出力

指定条件でレポートや一覧データをPDFとして生成・出力する。

出力種別

月次レポート / 顧客別レポート / 診療明細 など

F-014: ファイルアップロード

関連ファイルを検証後に保存し、対象データへ紐付けて管理する。

検証ルール

  • 拡張子: PDF, JPG, PNG
  • 容量: 1ファイル最大10MB

F-015: メール通知

テンプレートに基づき即時/予約でメール送信し、送信結果を記録する。

主な送信トリガー

  • 予約完了通知
  • 診療前日リマインド
  • 請求発行通知
