# フォルダ構成ガイド

## project_archive 関連
- ルート直下の既存ファイル群（`docs/`, `design/`, `prompts/` など）は、プロジェクトアーカイブ管理用です。

## 作成したフロントエンド実装
- `petlifeplus-site/` 配下に分離しています。
  - `petlifeplus-site/index.html`
  - `petlifeplus-site/concept.html`
  - `petlifeplus-site/service.html`
  - `petlifeplus-site/flow.html`
  - `petlifeplus-site/faq.html`
  - `petlifeplus-site/contact.html`
  - `petlifeplus-site/css/style.css`
  - `petlifeplus-site/js/main.js`

このため、`project_archive` 管理資料と、実装サイトファイルを判別できます。
